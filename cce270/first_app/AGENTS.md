# Project layout

This is a single-file web app. Keep `index.html` at the project root so GitHub
Pages can serve it. `spec.md` and `prompts.md` also belong at the root.

- `00_planning/`: notes and sketches
- `01_data/`: data files
- `02_validation/`: hand calculations and test cases
- `03_output/`: screenshots and exported results

Save new files in the folder that matches their purpose. Keep the root for the
files listed above and other project-level configuration or documentation.
